# Logic and Equation Quiz Game

A C# Windows Forms classroom game with truth-value and equation prompts, a score, lives, and a local high-score file. The original pixel-art backdrop and audio are included.

## Stack

C#, Windows Forms, .NET Framework 4.8.

## Run locally

Open `asds.sln` in Visual Studio on Windows, build, and run. Keep the supplied image and `Song.wav` beside the executable as configured by the project. Local high scores are not tracked.
